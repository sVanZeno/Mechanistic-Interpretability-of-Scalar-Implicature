# Mechanistic Interpretability of Scalar Implicature

Code for the paper **"Discourse Framing Activates a Structural Detection Head: Mechanistic Interpretability of Scalar Implicature Across Model Scales"** (BlackboxNLP @ EMNLP 2026, non-archival submission).

## Overview

We trace why a discourse-framed prompt template raises Pythia-1.4B's scalar implicature accuracy from 38% to 67%, identifying Layer 1 Head 3 (L01H03) as a structural detection head via a five-stage mechanistic interpretability pipeline.

## Repository Structure

```
├── stage0_environment/     # Environment setup and verification
├── stage1_prescreen/       # Stage 1a: Behavioral pre-screen on Pythia-1.4B
├── stage1_multimodel/      # Stage 1b: Scaling analysis (410M / 1.4B / 2.8B)
├── stage2_probing/         # Stage 2: Linear probing of residual streams
├── stage3_patching/        # Stage 3: Layer-level and head-level activation patching
├── stage4_head_analysis/   # Stage 4: L01H03 characterisation (attention, DLA, OV, ablation)
├── figures/                # Paper figures (generated by figures/make_all_figures.py)
└── paper/                  # LaTeX source (main.tex + references.bib)
```

## Reproducing the Experiments

```bash
pip install -r requirements.txt

# Stage 1: Behavioral evaluation
python stage1_prescreen/prescreen.py
python stage1_multimodel/run_multimodel_stage1.py

# Stage 2: Linear probing
python stage2_probing/probe.py

# Stage 3: Activation patching
python stage3_patching/patch_resid.py
python stage3_patching/patch_heads.py

# Stage 4: Head analysis
python stage4_head_analysis/analyze_L01H03.py

# Regenerate paper figures
python figures/make_all_figures.py
```

Results are saved as JSON files alongside each script and are also committed to the repo for reference.

## Dataset

We use the `implicature_quantifiers` split of [IMPPRES](https://github.com/tezign/IMPPRES) (Jeretiç et al., ACL 2020), 100 triplet items.

## Model

[Pythia-1.4B](https://huggingface.co/EleutherAI/pythia-1.4b) (EleutherAI), loaded via TransformerLens.
Scaling experiments additionally use Pythia-410M and Pythia-2.8B.
